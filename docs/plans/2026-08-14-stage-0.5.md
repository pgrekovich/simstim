# simstim Stage 0.5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the app look properly designed (shadcn/ui), add a settings dialog with a configurable output folder, and move model downloading into the app with progress, behind a multi-model-ready registry.

**Architecture:** Two new Rust modules in src-tauri (`config.rs`: JSON config load/save + commands; `models.rs`: static model registry + streaming downloader with progress events). Frontend rebuilt on Tailwind v4 + shadcn/ui: main screen (record button, status, transcript) + settings dialog (output folder via tauri-plugin-dialog, models list with download progress and active selection). `transcript::default_output_path` generalized to take a base directory.

**Tech Stack:** Existing workspace + reqwest (streaming), tar, bzip2, tauri-plugin-dialog; frontend: tailwindcss v4, shadcn/ui (button, card, dialog, select, progress, input, label), lucide-react icons.

## Global Constraints

- Config file: `~/Library/Application Support/simstim/config.json`, shape `{ "output_dir": "<abs path>", "active_model": "<model id>" }`. Defaults: `output_dir` = `~/Desktop`, `active_model` = `parakeet-tdt-0.6b-v3-int8`. Plain JSON via serde, no store plugins.
- Model registry ids: `parakeet-tdt-0.6b-v3-int8` (the only entry in 0.5; bundle = parakeet archive + silero_vad.onnx). Registry design must allow adding entries without touching UI code.
- Tauri IPC contract (exact names):
  - `get_config() -> Config { output_dir: String, active_model: String }`
  - `set_output_dir(path: String) -> Result<(), String>`
  - `set_active_model(id: String) -> Result<(), String>` (errors on unknown id)
  - `list_models() -> Vec<ModelInfo { id: String, name: String, size_mb: u64, downloaded: bool, active: bool }>`
  - `download_model(id: String) -> Result<(), String>` (async; progress via event)
  - Event `model-download-progress`, payload `{ id: String, phase: String, received: u64, total: u64 }` where phase is one of `download` | `extract` | `done` | `error` (on error, `received`/`total` = 0 and an additional `message: String` field is set)
  - Existing `start_recording`/`stop_recording`/`transcript-line` unchanged in name; `start_recording` now reads `output_dir` from config and must return Err("model not downloaded") if the active model's files are missing (no more failing at Stop).
- Model download URLs (canonical, from MVP-0):
  - `https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-nemo-parakeet-tdt-0.6b-v3-int8.tar.bz2` (~487 MB archive; dir renamed to `parakeet-tdt-0.6b-v3-int8` after extract)
  - `https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/silero_vad.onnx` (~644 KB)
- Models dir unchanged: `~/Library/Application Support/simstim/models/`. `scripts/download-models.sh` stays as a fallback and must remain compatible.
- UI: dark theme only (matches MVP-0), shadcn/ui components copied into `apps/desktop/src/components/ui/`, Tailwind v4. No UI framework beyond that, no light theme, no animations libraries.
- Status line states: `idle` | `loading model` | `recording` | `saved to <path>` | error text in red. "saved to" persists until the next Start.
- No telemetry, no network calls except the model downloads.
- No em dash characters in any authored text/copy. Conventional commits, no AI co-author lines.
- All existing tests stay green; new Rust logic gets TDD where it is not thin IO glue.

### Task 2: Model registry + in-app downloader

**Files:**
- Create: `apps/desktop/src-tauri/src/models.rs`
- Modify: `apps/desktop/src-tauri/src/lib.rs` (register commands), `apps/desktop/src-tauri/Cargo.toml` (reqwest stream+rustls, tar, bzip2, futures-util)
- Test: registry/status unit tests in-module (tempdir-based); download path is IO glue verified in Task 6 e2e

**Interfaces:**
- Consumes: `simstim_engine::models_dir()`, config from Task 1.
- Produces (Rust): `struct ModelSpec { id, name, size_mb, archive_url, archive_dir_name, dir_name, extra_files: &[(url, filename)] }`; `REGISTRY: &[ModelSpec]` (one entry; silero as extra_file); `fn is_downloaded(spec, models_dir) -> bool` (checks dir + tokens.txt + encoder + silero file exist); `fn model_ready(id) -> bool` used by start_recording's guard.
- Produces (IPC): `list_models`, `download_model` per Global Constraints. Download: reqwest stream to `<models_dir>/.download.tmp` emitting progress every >=1MB, then bzip2+tar extract (phase `extract`), rename dir, cleanup tmp, final `done` event. Any error: emit `error` phase with message AND return Err. Guard against concurrent downloads of the same id (Mutex<HashSet<id>> in state).
- Produces: `start_recording` gains the model-ready guard (`Err("model not downloaded: <name>")`).

- [ ] Step 1: TDD `is_downloaded` + registry lookup with tempdir fixtures
- [ ] Step 2: Implement registry + status + commands; downloader with progress events
