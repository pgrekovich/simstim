# Stage 2.0 implementation plan

## Global constraints

- Session `.md` files remain the only source of truth.
- Audio and transcript content stay local.
- Do not add Ask, chat, indexing, telemetry, or account behavior.
- Preserve the single-writer recording path and the mounted selected view.
- Keep authored code, comments, documentation, and UI copy in English.

## 1. Sidebar shell

- Add a locally persisted collapsed preference in `App`.
- Replace the inline search field with a global-search action.
- Add collapse and restore controls in the design-specified toolbar positions.
- Add the `Command+Backslash` toggle and component tests.

## 2. Global search dialog

- Replace the main-pane `SearchResults` screen with a modal palette.
- Reuse `search_sessions` and its existing debounce/cancellation semantics.
- Convert session hits into note and spoken rows, including safe parsing of
  transcript speaker and timestamp prefixes.
- Add empty, loading, error, keyboard navigation, click, and highlighting
  coverage.
- Wire `Command+K`, `Command+F`, and both toolbar search buttons.

## 3. Verification

- Run focused frontend tests while iterating.
- Run `cargo test --workspace`.
- Run `cargo clippy --workspace --all-targets -- -D warnings`.
- Run `pnpm test` and `pnpm build` from `apps/desktop`.
- Commit the spec, sidebar, and search work as separate conventional commits.
- Hand the stage to the owner for visual and end-to-end approval before merge.
