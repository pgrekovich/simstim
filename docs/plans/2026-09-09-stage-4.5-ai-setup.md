# Stage 4.5: AI setup without a terminal

## Objective

A clean Mac must not need developer tools to use optional summaries. Keep
one-screen onboarding and one-page settings. The owner wants no account
system or password form in simstim. Setup installs an official helper only
on a click and launches that helper's own browser sign-in.

## Constraints and implementation

- No simstim accounts, credentials database, OAuth client or token handling.
- Reuse working installed CLIs; otherwise download an unmodified native
  helper into simstim's Application Support directory. No npm, Homebrew,
  admin access, shell profile changes or remote install scripts.
- Verify upstream SHA-256 before installation, stage beside the destination
  and rename atomically. Only official HTTPS sources; bounded subprocesses,
  download limits, cancellation and cleanup on failure.
- Provider readiness includes a successful official authentication check,
  not just a version string. Authentication output is never shown or logged.
- Use the provider's official login command and browser flow. Existing
  credentials and authentication options remain the provider's responsibility.
- Setup must not send a note or consume a model request. Recording remains
  available when setup is skipped or fails.
- Existing authenticated CLI users retain their setup. Beta release was approved by the owner after successful manual acceptance. Four gates plus synthetic install/auth tests and owner e2e.

## Acceptance

On a clean Mac: choose a provider, install the helper, complete browser login,
then generate a summary without opening a terminal. Cancel and retry a setup;
close and reopen Settings while it runs. Existing CLI users should immediately
see the assistant as ready. Skip AI and record without an AI account.

## Validation, 2026-09-09

- Workspace tests: 487 passed, 9 ignored (manual/audio/model checks and the
  explicit helper download smoke test). Clippy and frontend build pass.
- UI tests: 228 passed, including setup opt-in, completion, cancel dispatch,
  retry, restored browser-login state and installed-but-signed-out status.
- Explicit official-download smoke test passed for both providers: downloaded
  to a scratch directory, verified, installed and executed `--version`. No
  login, logout, notes or model request was performed in this smoke test.
- Settings layout checked in the real renderer with fictional missing-helper
  fixtures. Native browser-login completion still needs owner clean-Mac e2e.
- Fixed a pre-existing banner test timing race: the listener registers before
  configuration and model readiness, so its happy-path test must await readiness.

push and release. Release target: `v0.11.0-beta.1`. Repository visibility
