# Security reports

Report security concerns privately through
[GitHub private vulnerability reporting](https://github.com/pgrekovich/simstim/security/advisories/new)
when available. If that form is unavailable, open a minimal issue asking
for a private reporting channel without disclosing exploit details or data.

Include affected versions, reproduction steps using synthetic files, impact
and a suggested fix if known. Do not attach real call recordings or secrets.
This is a small project, with no guaranteed response time or bug bounty.

The current beta is the supported version. Local storage is not application
encryption; macOS file permissions and the user's backup/sync choices apply.
The AI CLI and configured MCP servers are trusted dependencies, governed by
their own permissions and policies. See [privacy.md](docs/privacy.md).
