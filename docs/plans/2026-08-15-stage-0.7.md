# simstim Stage 0.7 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Keep the call audio next to the .md, add a whisper large-v3-turbo re-transcribe pass that fixes Russian quality, and let a click on a transcript line play that moment.

**Architecture:** The session worker gains an audio sink (interleaves the two 16 kHz mono channels into a stereo WAV while recording, encodes to FLAC on stop). A new whisper module in the engine crate wraps whisper-rs (Metal) for the offline pass. A `retranscribe_session` command decodes the FLAC, transcribes each channel, merges by timestamp, and rewrites the transcript section. The frontend gets an audio element fed through Tauri's asset protocol plus click-to-seek on transcript lines.

**Tech Stack:** existing workspace + `hound` (WAV write during capture), `flacenc` (encode on stop), `claxon` (decode for the pass), `whisper-rs 0.16` with the `metal` feature.

## Global Constraints

- Audio layout: ONE stereo file per session, **left = mic (Me), right = system (Them)**, 16 kHz, 16-bit. During recording it is `<session>.wav` (written incrementally so a crash leaves a playable file); on stop it is encoded to `<session>.flac` and the .wav is deleted. Same basename as the .md (`2026-08-15 14-30-05 call.md` -> `... call.flac`).
- Channel sync is approximate: keep a per-channel queue, write frames while both have samples, and if one channel leads the other by more than 1 second of samples, write the excess against silence so audio never stalls. Document the drift limitation in code.
- Retention is a config option: `keep_audio: bool` (default true). When false, no audio file is written at all and the re-transcribe action reports that audio is missing. No auto-deletion policy in 0.7.
- Re-transcribe REPLACES the transcript section; the previous text is not kept (owner's ruling: the app never edits transcripts, the file is the user's to hand-edit). Frontmatter `asr:` is updated to the model that produced the current text (`whisper-large-v3-turbo-q8` or `parakeet-tdt-0.6b-v3`). Title, notes, date and duration are preserved exactly.
- Whisper model ships through the EXISTING model registry as a second entry (id `whisper-large-v3-turbo-q8`, GGUF from the whisper.cpp Hugging Face repo; the implementer confirms the exact asset name and size with a HEAD request before hardcoding). Not downloaded by default; the re-transcribe action tells the user to download it when missing.
- whisper-rs is `0.16` with feature `metal`. Language: auto-detect. Segment timestamps come from whisper (`t0`/`t1` in centiseconds).
- Merging channels: transcribe left and right separately, tag Me/Them, merge into one list sorted by start time; timestamps are absolute from the start of the file.
- Re-transcribe never runs on the active recording session (reject with a user-facing message) and never blocks the UI: it runs off the main thread with progress events. IPC:
  - `retranscribe_session(path: String) -> Result<(), String>` (async; starts the job, rejects if one is already running or the session is active or audio/model is missing)
  - event `retranscribe-progress` payload `{ path: String, phase: "loading-model" | "transcribing" | "writing" | "done" | "error", channel: "me" | "them" | null, message: String | null }`
- Playback: the frontend plays the FLAC through Tauri's asset protocol (`convertFileSrc`), which requires the asset scope to cover the configured output dir. Clicking a transcript line seeks to that line's offset. No custom waveform, no scrubbing UI beyond the native controls in 0.7.
- All existing behavior stays: single-writer rule, format v2, atomic writes, live Parakeet pipeline untouched, no telemetry, no network beyond model downloads.
- No em dashes in authored copy. Conventional commits, no AI co-author lines. Every task ends with `cargo test --workspace`, `cargo clippy --workspace --all-targets -- -D warnings`, `pnpm test`, `pnpm build` all green.

### Task 1: Audio sink (stereo WAV during capture, FLAC on stop)

**Files:** new `apps/desktop/src-tauri/src/audio_sink.rs`; modify `session.rs` (feed chunks, finalize on stop), `config.rs` (`keep_audio`), `Cargo.toml` (hound, flacenc).

**Interfaces produced:**
- `AudioSink::new(base_path: &Path) -> Result<AudioSink>` where base_path is the .md path (derives the .wav/.flac siblings)
- `AudioSink::push(&mut self, channel: Channel, samples: &[f32])`
- `AudioSink::finish(self) -> Result<PathBuf>` (flush, close WAV, encode FLAC, remove WAV, return the FLAC path)
- `audio_path_for(md_path: &Path) -> PathBuf` (the .flac sibling; used by later tasks)
- Config gains `keep_audio: bool` (serde default true) + `set_keep_audio` command.

Sync rule per Global Constraints. Errors inside the sink must not kill the recording: report through the existing `session-error` path and continue transcribing without audio.

TDD: interleaving/padding logic as a pure function (equal streams, one channel starved, one channel far ahead), round-trip test (push known samples -> finish -> decode the FLAC with claxon -> assert channel content and sample count), `keep_audio=false` writes nothing.

Commit `feat(audio): retain call audio as stereo flac next to the transcript`.

### Task 3: Re-transcribe command

**Files:** new `apps/desktop/src-tauri/src/retranscribe.rs`, `lib.rs` (command + state), `sessions.rs` (rewrite with a new transcript + asr field), `crates/transcript/src/lib.rs` (asr field becomes settable), `src/lib/ipc.ts` (types).

**Behavior:** per Global Constraints. Decode FLAC via claxon, split L/R to f32, run whisper per channel with progress events, merge sorted, format as `[hh:mm:ss] Me:/Them: text`, then rewrite the session file preserving title/notes/date/duration and setting `asr:`. Reject: active session, missing audio, missing model, another job running. The rewrite is a single atomic write at the end (no partial transcript states on disk).

Tests: merge/format logic as pure functions (interleaved segments from both channels, empty channel, overlapping segments); rewrite preserves title/notes/date/duration and updates asr (fixture-based, no whisper needed); all four rejection paths.

Commit `feat(session): re-transcribe a call with whisper`.

### Task 4: Playback and click-to-seek

**Files:** `apps/desktop/src/components/SessionView.tsx`, `TranscriptView.tsx`, `src/lib/ipc.ts`, `src-tauri/tauri.conf.json` + capabilities (asset protocol scope for the output dir).

**Behavior:** when the open session has an audio file (new field on `SessionData`: `audio_path: string | null`, filled by `read_session`), render a compact `<audio controls>` above the transcript fed by `convertFileSrc(audio_path)`. Clicking a transcript line sets `audio.currentTime` to that line's offset and plays. The active line while playing gets a subtle highlight (optional if it costs much: keep it simple). No audio: no player, transcript unchanged. Re-transcribe button lives in the session header area with progress text driven by `retranscribe-progress`, disabled while recording or while a job runs.

Tests: line-click computes the right offset from the parsed timestamp; player hidden when audio_path is null.

Commit `feat(ui): audio playback with click to seek and a re-transcribe action`.

## Self-review notes

- Task order is dependency-clean: 1 (audio exists) -> 2 (whisper works) -> 3 (uses both) -> 4 (UI over 3) -> 5.
- The registry was built multi-model-ready in stage 0.5, so Task 2's entry is the first real test of that design; if `ModelSpec` needs an "archive-less single file" shape, that is expected work, not scope creep.
- Risk: whisper-rs build time and Metal availability. Already verified on this machine (34s clean build, CLT only, no Xcode) during research; if it regresses, the task reports BLOCKED rather than silently switching runtimes.
- Risk: hound writes 16-bit PCM, our pipeline is f32; conversion is lossy at the sample level but inaudible and matches what the ASR consumes anyway.
