# simstim MVP-0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A macOS Tauri app with one Start/Stop button that captures mic + system audio, transcribes both near-real-time (VAD-chunked Parakeet), and continuously saves a `.md` transcript to the Desktop.

**Architecture:** Cargo workspace: three library crates (`capture` = cpal mic + cidre system-audio tap producing 16kHz mono f32 chunks per channel; `engine` = Silero VAD + Parakeet TDT v3 via the official sherpa-onnx crate; `transcript` = ordered segment store + atomic .md writer) glued by a Tauri 2 app (`apps/desktop`) that exposes start/stop commands and streams transcript events to a minimal React UI.

**Tech Stack:** Rust (edition 2024), Tauri 2, React+TS (vite), sherpa-onnx 1.13.5 (official crate), cidre 0.15, cpal 0.17.

## Global Constraints

- macOS 14.2+ only (Core Audio process taps). Dev machine: macOS 26.5, Apple Silicon.
- Pinned versions, verified against reference code: `sherpa-onnx = "1.13.5"`, `cidre = "0.15"` (NOT 0.20: API churns; anarlog's verified tap code is 0.15), `cpal = "0.17"` (0.17.3: matches anarlog's verified mic code; note 0.18 renamed device identity APIs).
- ASR model: Parakeet TDT 0.6b v3 int8, canonical archive `https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-nemo-parakeet-tdt-0.6b-v3-int8.tar.bz2` (~487 MB). VAD model: `https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/silero_vad.onnx`. Models live in `~/Library/Application Support/simstim/models/`, never in the repo or the binary.
- `model_type: "nemo_transducer"` is REQUIRED in the recognizer config, silently broken without it.
- VAD window size at 16 kHz is exactly 512 samples: feed `accept_waveform` in 512-sample windows.
- Info.plist must carry `NSMicrophoneUsageDescription` AND `NSAudioCaptureUsageDescription`.
- Output file: reduced spec format: YAML frontmatter + `## Transcript` with `[hh:mm:ss] Me:/Them:` lines. Filename: `YYYY-MM-DD HH-mm call.md` on the Desktop.
- Transcript file is always complete on disk: full rewrite to temp file + atomic rename on every finalized segment. Never append-only partial writes, never in-memory-only state.
- No telemetry, no network calls except the model download script.
- Commit messages: conventional prefixes (feat/fix/docs/chore), no AI co-author lines.
- During `tauri dev` the TCC grants (mic + system audio) attach to the parent terminal app; iTerm sometimes fails to prompt silently. If capture yields silence, check System Settings > Privacy & Security (mic; and "Screen & System Audio Recording" for the tap).

```rust
use anyhow::{Context, Result};
use sherpa_onnx::{
    OfflineRecognizer, OfflineRecognizerConfig, OfflineTransducerModelConfig,
    VadModelConfig, VoiceActivityDetector,
};
use std::path::{Path, PathBuf};

pub fn models_dir() -> PathBuf {
    dirs::data_dir().expect("no data dir").join("simstim/models")
}

pub struct Segment {
    pub start_sample: usize,
    pub samples: Vec<f32>,
}

pub struct Engine {
    recognizer: OfflineRecognizer,
}

impl Engine {
    pub fn new(models: &Path) -> Result<Self> {
        let m = models.join("parakeet-tdt-0.6b-v3-int8");
        let mut config = OfflineRecognizerConfig::default();
        config.model_config.transducer = OfflineTransducerModelConfig {
            encoder: Some(m.join("encoder.int8.onnx").to_string_lossy().into()),
            decoder: Some(m.join("decoder.int8.onnx").to_string_lossy().into()),
            joiner: Some(m.join("joiner.int8.onnx").to_string_lossy().into()),
        };
        config.model_config.tokens = Some(m.join("tokens.txt").to_string_lossy().into());
        config.model_config.model_type = Some("nemo_transducer".into());
        config.model_config.num_threads = 4;
        let recognizer = OfflineRecognizer::create(&config)
            .context("recognizer create failed (bad config? see stderr)")?;
        Ok(Self { recognizer })
    }

    pub fn transcribe(&self, samples: &[f32]) -> String {
        let stream = self.recognizer.create_stream();
        stream.accept_waveform(16000, samples);
        self.recognizer.decode(&stream);
        stream.get_result().map(|r| r.text).unwrap_or_default()
    }
}

const VAD_WINDOW: usize = 512;

pub struct Vad {
    vad: VoiceActivityDetector,
    pending: Vec<f32>,
}

impl Vad {
    pub fn new(models: &Path) -> Result<Self> {
        let mut config = VadModelConfig::default();
        config.silero_vad.model = Some(models.join("silero_vad.onnx").to_string_lossy().into());
        config.silero_vad.threshold = 0.5;
        config.silero_vad.min_silence_duration = 0.4;
        config.silero_vad.min_speech_duration = 0.25;
        config.silero_vad.max_speech_duration = 8.0;
        config.silero_vad.window_size = VAD_WINDOW as i32;
        config.sample_rate = 16000;
        config.num_threads = 1;
        let vad = VoiceActivityDetector::create(&config, 60.0)
            .context("vad create failed")?;
        Ok(Self { vad, pending: Vec::new() })
    }

    pub fn push(&mut self, samples: &[f32]) -> Vec<Segment> {
        self.pending.extend_from_slice(samples);
        let mut out = Vec::new();
        while self.pending.len() >= VAD_WINDOW {
            let window: Vec<f32> = self.pending.drain(..VAD_WINDOW).collect();
            self.vad.accept_waveform(&window);
            self.drain_segments(&mut out);
        }
        out
    }

    pub fn flush(&mut self) -> Vec<Segment> {
        self.vad.flush();
        let mut out = Vec::new();
        self.drain_segments(&mut out);
        out
    }

    fn drain_segments(&mut self, out: &mut Vec<Segment>) {
        while !self.vad.is_empty() {
            if let Some(seg) = self.vad.front() {
                out.push(Segment {
                    start_sample: seg.start().max(0) as usize,
                    samples: seg.samples().to_vec(),
                });
            }
            self.vad.pop();
        }
    }
}
```

API-shape caution: the exact method names on `VoiceActivityDetector`/segment (`front()`, `start()`, `samples()`, `pop()`, `is_empty()`, `flush()`) and on the recognizer result are per sherpa-onnx 1.13.5 as extracted from its source; if the compiler disagrees, the ground truth is `~/.cargo/registry/src/*/sherpa-onnx-1.13.5/src/{vad.rs,offline_asr.rs}` and the reference example `rust-api-examples/examples/parakeet_tdt_simulate_streaming_microphone.rs` in k2-fsa/sherpa-onnx. Fix the call sites, not the architecture.

- [ ] **Step 4: Implement lib.rs (types + linear resampler)**

```rust
pub mod mic;
#[cfg(target_os = "macos")]
pub mod speaker;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Channel { Me, Them }

pub struct Chunk {
    pub channel: Channel,
    pub samples: Vec<f32>,
}

/// Linear-interpolation resampler to 16 kHz. `carry` holds the last input
/// sample + fractional position across calls so chunk boundaries stay smooth.
/// Good enough for ASR (the official sherpa-onnx mic example ships the same).
pub(crate) fn resample_to_16k(input: &[f32], from_rate: u32, carry: &mut Vec<f32>) -> Vec<f32> {
    if from_rate == 16000 {
        return input.to_vec();
    }
    // carry layout: [prev_sample, frac_pos]
    if carry.is_empty() { carry.extend_from_slice(&[0.0, 0.0]); }
    let ratio = from_rate as f64 / 16000.0;
    let mut out = Vec::with_capacity((input.len() as f64 / ratio) as usize + 2);
    let mut pos = carry[1] as f64;
    let prev = carry[0];
    let get = |i: i64| -> f32 {
        if i < 0 { prev } else { input[i as usize] }
    };
    while (pos as i64) < input.len() as i64 {
        let i = pos.floor() as i64;
        let frac = (pos - pos.floor()) as f32;
        let a = get(i - 1 + 1); // current sample (i), with -1 meaning prev
        let _ = a;
        let s0 = get(i - 1 + 1 - 1); // sample before pos
        let s1 = get(i);
        out.push(s0 + (s1 - s0) * frac);
        pos += ratio;
    }
    carry[0] = *input.last().unwrap_or(&carry[0]);
    carry[1] = (pos - input.len() as f64) as f32;
    out
}
```

Note: the index arithmetic above is fiddly on purpose to show intent; implementer should simplify (`s0 = sample at floor(pos)-adjacent boundary handling`) while keeping both tests green, and add a third test: feeding a 48 kHz sine in two halves produces the same output as feeding it whole (carry correctness).

- [ ] **Step 6: Implement `mic.rs`**

Pattern from anarlog `crates/audio-actual/src/mic.rs` (cpal streams are `!Send` on macOS: own the stream on a dedicated thread, tear down via mpsc):

```rust
use crate::{resample_to_16k, Channel, Chunk};
use anyhow::{anyhow, Result};
use cpal::traits::{DeviceTrait, HostTrait, StreamTrait};
use std::sync::mpsc::{channel, Sender};

pub struct CaptureHandle {
    drop_tx: Sender<()>,
}

impl Drop for CaptureHandle {
    fn drop(&mut self) { let _ = self.drop_tx.send(()); }
}

pub fn start_mic(tx: Sender<Chunk>) -> Result<CaptureHandle> {
    let (drop_tx, drop_rx) = channel::<()>();
    let (ready_tx, ready_rx) = channel::<Result<()>>();

    std::thread::spawn(move || {
        let build = || -> Result<cpal::Stream> {
            let host = cpal::default_host();
            let device = host.default_input_device().ok_or_else(|| anyhow!("no input device"))?;
            // never bind to our own tap aggregate device
            if let Ok(desc) = device.description() {
                if desc.name().contains("simstim") { return Err(anyhow!("default input is our tap")); }
            }
            let config = device.default_input_config()?;
            let rate = config.sample_rate().0;
            let channels = config.channels() as usize;
            let mut carry = Vec::new();
            let stream = device.build_input_stream(
                &config.into(),
                move |data: &[f32], _: &cpal::InputCallbackInfo| {
                    let mono: Vec<f32> = data.chunks(channels)
                        .map(|f| f.iter().sum::<f32>() / channels as f32)
                        .collect();
                    let out = resample_to_16k(&mono, rate, &mut carry);
                    let _ = tx.send(Chunk { channel: Channel::Me, samples: out });
                },
                |e| eprintln!("mic stream error: {e}"),
                None,
            )?;
            stream.play()?;
            Ok(stream)
        };
        match build() {
            Ok(stream) => {
                let _ = ready_tx.send(Ok(()));
                let _ = drop_rx.recv(); // park until handle dropped
                drop(stream);
            }
            Err(e) => { let _ = ready_tx.send(Err(e)); }
        }
    });

    ready_rx.recv_timeout(std::time::Duration::from_secs(5))
        .map_err(|_| anyhow!("mic init timeout"))??;
    Ok(CaptureHandle { drop_tx })
}
```

(If cpal 0.17.3's `device.description()` shape differs, use whatever name accessor 0.17.3 exposes; ground truth is anarlog's mic.rs which compiles against 0.17.)

- [ ] **Step 1: Implement `speaker.rs` with cidre**

Reference implementation to mirror: anarlog `crates/audio-actual/src/speaker/macos.rs` (cidre 0.15, MIT) and Swift semantics in makeusabrew/audiotee. Sequence: mono global tap excluding no processes -> process tap -> private aggregate device with the tap in its tap list -> IOProc -> start. Condensed target shape:

```rust
use crate::{resample_to_16k, Channel, Chunk};
use anyhow::Result;
use cidre::{cat, cf, core_audio as ca, ns, os};
use std::sync::mpsc::Sender;

struct Ctx {
    tx: Sender<Chunk>,
    rate: u32,
    carry: Vec<f32>,
}

extern "C" fn io_proc(
    _device: ca::Device, _now: &cat::AudioTimeStamp,
    input: &cat::AudioBufList<1>, _in_time: &cat::AudioTimeStamp,
    _out: &mut cat::AudioBufList<1>, _out_time: &cat::AudioTimeStamp,
    ctx: Option<&mut Ctx>,
) -> os::Status {
    if let Some(ctx) = ctx {
        let buf = &input.buffers[0];
        let n = buf.data_bytes_size as usize / size_of::<f32>();
        let samples = unsafe { std::slice::from_raw_parts(buf.data as *const f32, n) };
        let out = resample_to_16k(samples, ctx.rate, &mut ctx.carry);
        let _ = ctx.tx.send(Chunk { channel: Channel::Them, samples: out });
    }
    os::Status::NO_ERR
}

pub fn start_speaker(tx: Sender<Chunk>) -> Result<SpeakerHandle> {
    let tap_desc = ca::TapDesc::with_mono_global_tap_excluding_processes(&ns::Array::new());
    let tap = tap_desc.create_process_tap()?;
    let rate = tap.asbd()?.sample_rate as u32;
    let tap_uid = tap.uid()?;

    use ca::aggregate_device_keys as agg;
    let sub_tap = cf::DictionaryOf::with_keys_values(
        &[ca::sub_device_keys::uid()], &[tap_uid.as_type_ref()]);
    let desc = cf::DictionaryOf::with_keys_values(
        &[agg::is_private(), agg::tap_auto_start(), agg::name(), agg::uid(), agg::tap_list()],
        &[cf::Boolean::value_true().as_type_ref(),
          cf::Boolean::value_true(),
          cf::String::from_str("simstim-tap").as_ref(),
          &cf::Uuid::new().to_cf_string(),
          &cf::ArrayOf::from_slice(&[sub_tap.as_ref()])]);

    let device = ca::AggregateDevice::with_desc(&desc)?;
    let ctx = Box::new(Ctx { tx, rate, carry: Vec::new() });
    let ctx_ref = Box::leak(ctx); // freed in SpeakerHandle::drop
    let proc_id = device.create_io_proc_id(io_proc, Some(ctx_ref))?;
    let started = ca::device_start(device, Some(proc_id))?;
    Ok(SpeakerHandle { _tap: tap, _started: started, ctx: ctx_ref as *mut Ctx })
}
```

Follow anarlog for the exact ownership/teardown details (they keep `TapGuard` + `StartedDevice` as struct fields and let drop order tear down; prefer their pattern over the leak/free sketch above if it maps cleanly). The IOProc must stay allocation-light; the mpsc send of a small Vec is acceptable for MVP-0.

Format caution: real taps deliver f32, but mirror anarlog's defensive format check (read the ASBD once at setup; if the common format is not PcmF32, convert per-format like they do).

```rust
use anyhow::Result;
use chrono::{DateTime, Local};
use std::path::{Path, PathBuf};

#[derive(Clone, Copy, PartialEq, Eq)]
pub enum Speaker { Me, Them }

struct Line { speaker: Speaker, offset_secs: f64, text: String }

pub struct Transcript { started_at: DateTime<Local>, lines: Vec<Line> }

impl Transcript {
    pub fn new(started_at: DateTime<Local>) -> Self {
        Self { started_at, lines: Vec::new() }
    }

    pub fn add(&mut self, speaker: Speaker, offset_secs: f64, text: String) {
        let text = text.trim().to_string();
        if text.is_empty() { return; }
        let idx = self.lines.partition_point(|l| l.offset_secs <= offset_secs);
        self.lines.insert(idx, Line { speaker, offset_secs, text });
    }

    pub fn render(&self) -> String {
        let mut out = format!(
            "---\ndate: {}\nasr: parakeet-tdt-0.6b-v3\n---\n\n## Transcript\n\n",
            self.started_at.to_rfc3339_opts(chrono::SecondsFormat::Secs, false),
        );
        for l in &self.lines {
            let s = l.offset_secs as u64;
            let who = match l.speaker { Speaker::Me => "Me", Speaker::Them => "Them" };
            out.push_str(&format!("[{:02}:{:02}:{:02}] {}: {}\n", s / 3600, (s % 3600) / 60, s % 60, who, l.text));
        }
        out
    }

    pub fn save(&self, path: &Path) -> Result<()> {
        let tmp = path.with_extension("md.tmp");
        std::fs::write(&tmp, self.render())?;
        std::fs::rename(&tmp, path)?;
        Ok(())
    }
}

pub fn default_output_path(started_at: DateTime<Local>) -> PathBuf {
    let home = dirs::home_dir().expect("no home dir");
    home.join("Desktop").join(format!("{} call.md", started_at.format("%Y-%m-%d %H-%M")))
}
```

**Files:**
- Create: `apps/desktop/src-tauri/src/session.rs`
- Test: `apps/desktop/src-tauri/tests/session.rs` (file-driven, no audio hardware)

**Interfaces:**
- Consumes: everything above.
- Produces:
  - `Session::start(chunk_rx: Receiver<Chunk>, out_path: PathBuf, on_line: impl Fn(String) + Send + 'static) -> Session`: spawns the worker thread; `on_line` fires per finalized transcript line (already formatted, for the UI).
  - `Session::stop(self) -> anyhow::Result<PathBuf>`: signals stop, joins the worker (which flushes both VADs, transcribes remainders, final save), returns the output path.
  - Session owns: one `Engine` (shared), two `Vad`s (Me/Them), running sample counters per channel for offsets, one `Transcript`.

Worker loop design (single thread is enough: chunks are small, ASR runs on the same thread serially; if a segment decodes slower than real time the mpsc queue absorbs the burst):

```rust
loop {
    match chunk_rx.recv_timeout(Duration::from_millis(200)) {
        Ok(chunk) => {
            let (vad, counter) = per_channel(&chunk.channel);
            let base = *counter;                       // samples seen before this chunk
            *counter += chunk.samples.len();
            for seg in vad.push(&chunk.samples) {
                let text = engine.transcribe(&seg.samples);
                let offset = seg.start_sample as f64 / 16000.0; // vad counts from its own stream start
                transcript.add(speaker_of(chunk.channel), offset, text);
                transcript.save(&out_path)?;
                on_line(formatted_line);
            }
            let _ = base; // NB: vad's seg.start_sample is already stream-absolute; verify in test
        }
        Err(RecvTimeoutError::Timeout) => { if stop_flag { break; } }
        Err(Disconnected) => break,
    }
}
// on stop: for each vad: flush() -> transcribe -> add; final save
```

```rust
mod session;
use std::sync::Mutex;
use tauri::{AppHandle, Emitter, Manager, State};

struct Recording {
    session: session::Session,
    _mic: simstim_capture::mic::CaptureHandle,
    _speaker: simstim_capture::speaker::SpeakerHandle,
}
struct AppState(Mutex<Option<Recording>>);

#[tauri::command]
fn start_recording(app: AppHandle, state: State<AppState>) -> Result<String, String> {
    let mut guard = state.0.lock().unwrap();
    if guard.is_some() { return Err("already recording".into()); }
    let (tx, rx) = std::sync::mpsc::channel();
    let mic = simstim_capture::mic::start_mic(tx.clone()).map_err(|e| e.to_string())?;
    let speaker = simstim_capture::speaker::start_speaker(tx).map_err(|e| e.to_string())?;
    let out = simstim_transcript::default_output_path(chrono::Local::now());
    let emitter = app.clone();
    let session = session::Session::start(rx, out.clone(), move |line| {
        let _ = emitter.emit("transcript-line", line);
    });
    *guard = Some(Recording { session, _mic: mic, _speaker: speaker });
    Ok(out.display().to_string())
}

#[tauri::command]
fn stop_recording(state: State<AppState>) -> Result<String, String> {
    let rec = state.0.lock().unwrap().take().ok_or("not recording")?;
    // capture handles drop here -> streams stop -> tx senders drop -> session drains
    let path = rec.session.stop().map_err(|e| e.to_string())?;
    Ok(path.display().to_string())
}
```

Register both commands and `manage(AppState(Mutex::new(None)))` in the builder. Engine load (~seconds) happens inside `Session::start` on the worker thread: the UI shows "loading model" until the first status event; simplest acceptable MVP behavior.
