# Bundled fonts

These font files are application assets. They are loaded locally and never
requested from a font CDN at runtime.

## Source Serif 4

- Source: https://github.com/google/fonts/tree/main/ofl/sourceserif4
- Files: `SourceSerif4-Variable.ttf` and
  `SourceSerif4-Italic-Variable.ttf`
- License: SIL Open Font License 1.1 in `SourceSerif4-OFL.txt`

## Spline Sans Mono

- Source: https://github.com/google/fonts/tree/main/ofl/splinesansmono
- File: `SplineSansMono-Variable.ttf`
- License: SIL Open Font License 1.1 in `SplineSansMono-OFL.txt`

Helvetica Neue is intentionally not bundled. The UI uses the copy supplied by
macOS and falls back to the native system sans serif on other platforms.
