# Stage 1.2: interface redesign

2026-08-27. Status: shipped after the owner's final visual and native e2e.
Approved for merge and release as v0.6.0. The agent-side verification passed
clippy, the production frontend build, and all 127 frontend tests in a
single-worker run. The standard Rust suite remains dependent on the release CI
environment for system AAC, Core Audio, Finder Apple Events, and long real-VAD
coverage.

## Global constraints

- Follow `docs/specs/2026-08-26-interface-redesign.md`.
- Do not change capture, transcript persistence, save routing, or file format.
- Do not add designed future features in this stage.
- Do not fetch fonts or assets at runtime.
- Preserve current accessible names and tested behavior.
- Finish with all four repository gates green and owner e2e before merge.

## Task 1: establish tokens and type roles

- Replace stock neutral shadcn tokens with the paper/tape palette.
- Add explicit roles for body, serif reading text, mono metadata, ochre voice,
  recording red, panels, and hairlines.
- Add reduced-motion handling for the recording tally.
- Restyle shared buttons, inputs, tabs, cards, menus, dialog, slider, progress,
  checkbox, and select through tokens before adding component exceptions.

Verification: component tests and a production frontend build.

## Task 2: main shell and session list

- Move to the 224 px sidebar and 56 px title-bar rhythm.
- Restyle new note, search, grouped headings, session rows, selected state,
  recording marker, deletion affordance, and settings footer.
- Restyle the main header, status line, Record/Stop control, note menu, main
  padding, search results, and empty state.
- Exercise long titles, empty lists, no matches, errors, active recording, and
  model-missing states.

Verification: `Sidebar`, `SearchResults`, `RecordButton`, `EmptyState`, and
`App` tests.

## Task 3: content surfaces

- Restyle title editing and Notes as an unboxed writing surface.
- Give Summary a separate generated-text material and retain provenance.
- Convert Transcript from console lines into readable turns without changing
  parsing, raw-line fallback, seek behavior, or interim state.
- Restyle the audio player around the real seek slider and existing controls.
- Preserve mounted tab content so playback and scroll state survive switching.

Verification: `SessionView` and `TranscriptView` tests, plus manual playback and
seek checks in the app.

## Task 4: settings and call banner

- Apply the visual language to the existing dialog navigation, groups, rows,
  model states, progress, confirmation, and errors.
- Apply the same palette and type roles to detected, call-ended, dropdown, and
  timer states in the floating banner.
- Do not change the banner window, focus behavior, event routing, or timers.

Verification: settings and banner tests, then a real detected-call e2e.
