# Stage 2.1 implementation plan

## Global constraints

- Session `.md` files remain the only source of truth.
- Search stays local and read-only. Do not add an index, cache, telemetry, or
  network call.
- Do not edit transcript text or search interim text.
- Preserve the single-writer recording path and mounted selected view.
- Keep authored code, comments, documentation, and UI copy in English.
- Work on a feature branch and do not merge without the owner's explicit
  approval.

## 1. Find model and transcript rendering

- Add a deterministic case-insensitive match helper over finalized transcript
  text.
- Render all and active highlights without changing click-to-seek behavior.
- Scroll the active occurrence into view and keep live transcript auto-scroll
  from fighting explicit find navigation.
- Add focused helper, rendering, navigation, and accessibility tests.

## 2. Session toolbar controls

- Control the selected session tab so `Command+F` and external navigation can
  activate Transcript.
- Portal the design-matched find field, count, previous, next, and close
  controls into the main toolbar.
- Support Enter, Shift+Enter, Escape, wraparound, focus, empty, and no-result
  states.

## 3. Global result handoff

- Preserve a typed navigation request in App while the destination session
  loads.
- Extend spoken result opening with its query and timestamp while note rows
  retain plain open behavior.
- Cover cross-session and same-session spoken navigation in component tests.

## 4. Verification and handoff

- Run focused frontend tests while iterating.
- Run `cargo test --workspace`.
- Run `cargo clippy --workspace --all-targets -- -D warnings`.
- Run `pnpm test` and `pnpm build` from `apps/desktop`.
- Commit documentation and implementation in small conventional commits.
- Push the feature branch for owner testing. Do not merge it.
